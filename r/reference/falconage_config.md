# What this installation resolved to

Versions, available compute devices, and the size and version of the
clock registry. The same information `falconage config` prints on the
command line and `falconage.config()` returns in Python – one function,
three surfaces, so a bug report from any of them is comparable.

## Usage

``` r
falconage_config()

# S3 method for class 'falcon_config'
print(x, ...)
```

## Arguments

- x:

  A `falcon_config`.

- ...:

  Ignored.

## Value

A named list, invisibly when printing.

## Examples

``` r
if (FALSE) { # \dontrun{
falconage_config()
} # }
```
