# The shared categorical palette

Okabe-Ito, colour-blind safe, ordered so the first two entries – what a
two-group comparison uses – are the most separable pair in the set.

## Usage

``` r
falcon_palette(which = "categorical")
```

## Arguments

- which:

  `"categorical"`, `"sequential"`, or a name under `semantic`.

## Value

A character vector of hex colours, or one colour for a semantic role.

## Examples

``` r
if (FALSE) { # \dontrun{
falcon_palette()
falcon_palette("case")
} # }
```
