# Everything the registry knows about one clock

## Usage

``` r
clock_info(clock_id)
```

## Arguments

- clock_id:

  A clock identifier.

## Value

A named list, invisibly. Printed for reading.

## Examples

``` r
if (FALSE) { # \dontrun{
clock_info("horvath2013")
clock_info("dnamphenoage")
} # }
```
