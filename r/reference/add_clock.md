# Add a clock of your own for this session

The clock is then scored like any catalogue clock, with coverage, the
specimen check, technical standard errors and a manifest entry.

## Usage

``` r
add_clock(path, replace = FALSE)
```

## Arguments

- path:

  A YAML clock entry, or a folder holding exactly one.

- replace:

  Replace a clock of your own added earlier under the same id.

## Value

The clock id.
