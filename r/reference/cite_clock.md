# Cite a clock

Cite a clock

## Usage

``` r
cite_clock(clock_id, style = c("plain", "bibtex"))
```

## Arguments

- clock_id:

  A clock identifier.

- style:

  `"plain"` or `"bibtex"`.

## Value

A character string.

## Examples

``` r
if (FALSE) { # \dontrun{
cite_clock("horvath2013")
cat(cite_clock("dnamphenoage", "bibtex"))
} # }
```
